# 会话面包屑（journal）

任何**实质性修改了代码或文档**的会话，在完成主任务的同一条回复末尾，
向 `projects/<当前study>/notes/journal.md` 追加一行（文件不存在则创建）：

```
- YYYY-MM-DD <repo或范围>：改了什么（一句话）｜为什么（数据变化/业务背景/拍板结论，一句话）
```

规则：

1. 只追加，不整理——压实是每日 /close-out 的事。
2. "为什么"必须写背景原因，不是复述改动本身。
3. 纯问答、未改任何文件的会话不写。
4. 这一行是主任务回复的一部分，**不要**为它单独发起新一轮对话或向用户提问。
